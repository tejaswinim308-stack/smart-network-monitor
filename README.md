# Smart Network Monitoring & Alert System

## Description



Smart Network Monitoring & Alert System is a Python app that simulates monitoring of enterprise-class network infrastructure. The application allows to monitor devices, measure packet latency, log data about system’s performance and send out notifications upon system failure.



## Features



- Enterprise-grade monitoring

- Latency detection

- CSV-formatted logging

- Alert notification system

- Powerful visualization

- Lightweight and easy to use

## Technologies

- Python

- Pandas

- Matplotlib

- Mail server

- Subprocess

## Architecture

Monitoring service periodically pings servers, logs statistical data to CSV-file and send out emails about detected failures. The performance data is visualized on a chart generated by a separate script.

## Getting Started

### Installation

Install dependencies by running

```pip install -r requirements.txt```

### Usage

Launch the monitoring utility by typing



```python monitor.py```

Visualize performance data by launching

```python visualize.py```

## Notes

The application was built as a utility to demonstrate the concept of enterprise network monitoring.
